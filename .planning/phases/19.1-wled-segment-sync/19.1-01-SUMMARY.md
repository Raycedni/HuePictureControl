## Decisions Made

- **Two-stage skip-gate for `fetch_wled_state` stubs.** `services.wled_client` already exists (it holds `fetch_wled_info`), so `pytest.importorskip("services.wled_client")` alone wouldn't skip — it would import the existing module and then crash on the missing function. Solution: combine `importorskip` with a `hasattr(wled_client, "fetch_wled_state")` check, then `pytest.skip("Plan 02 wires this — stub only")` after. Guarantees SKIPPED for every case in every state of the codebase.
- **Pre-existing test failures left alone per scope rules.** 12 `test_cameras_router.py` tests fail on `master` regardless of Plan 01 changes (verified by `git stash` + re-run). Scope boundary: only auto-fix issues directly caused by current changes. Logged to `deferred-items.md`.
