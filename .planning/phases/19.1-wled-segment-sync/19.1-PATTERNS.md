**Analog A — transaction wrapper:** `Backend/services/wled_channels.py:74-223` (`create_channel_with_split`)
**Analog B — cascade pattern:** `Backend/services/wled_channels.py:306-335` (`delete_channel_with_cascade`)

**Module docstring + import pattern** (mirror `wled_channels.py:1-31`):
```python
"""Phase 19.1: WLED segment-cache reconciliation transaction.

Owns the DELETE/INSERT-then-cascade write that mirrors a device's `/json/state
seg[]` into `wled_seg_cache` and hard-deletes orphan `wled_light_assignments`
rows pointing at vanished segments (D-14, D-15, D-19).

Transactional model: mirrors wled_channels.py — implicit aiosqlite transaction,
explicit db.commit(), try/except with db.rollback() on failure. Cascade runs
in application code because SQLite FK enforcement is OFF (see database.py
comment at lines 92-97).
"""
from __future__ import annotations

import logging
from datetime import datetime, timezone

import aiosqlite

logger = logging.getLogger(__name__)
```

**Core reconcile pattern — copy try/commit/rollback shape from `wled_channels.py:178-215`:**
```python
# Pattern source: wled_channels.py:178-215 (create_channel_with_split's
# transaction body) — keep the try/commit/except/rollback skeleton verbatim;
# replace per-row mutations with the D-14 three-step DELETE/INSERT/cascade.
try:
    await db.execute(
        "DELETE FROM wled_seg_cache WHERE device_id = ?", (device_id,)
    )
    await db.executemany(
        "INSERT INTO wled_seg_cache "
        "(device_id, seg_index, start_led, stop_led, name, refreshed_at) "
        "VALUES (?, ?, ?, ?, ?, ?)",
        [(device_id, s["seg_index"], s["start_led"], s["stop_led"],
          s.get("name"), now_iso) for s in segments],
    )
    cur = await db.execute(
        "DELETE FROM wled_light_assignments "
        "WHERE wled_device_id = ? AND seg_index NOT IN ("
        "    SELECT seg_index FROM wled_seg_cache WHERE device_id = ?"
        ")",
        (device_id, device_id),
    )
    dropped = cur.rowcount or 0
    await db.commit()
    return dropped
except Exception:
    await db.rollback()
    raise
```

**Keep:** the try/commit/except/rollback skeleton, `cur.rowcount or 0` idiom (also used at `routers/wled.py:792-798`), defensive logger import.
**Change:** all mutations are pure CRUD on `wled_seg_cache` + cascade on `wled_light_assignments` — no overlap-split geometry, no UUID generation, no name-counter increment.
