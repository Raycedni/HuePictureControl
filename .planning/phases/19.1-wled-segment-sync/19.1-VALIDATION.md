## Sampling Rate

- **After every task commit:** Run targeted pytest module for affected file (e.g. `python -m pytest Backend/tests/test_wled_segments.py -x`) or `npx vitest run <file>` for frontend
- **After every plan wave:** Run full backend `python -m pytest` + frontend `npx vitest run`
- **Before `/gsd-verify-work`:** Full suite green + `Skill(skill="preflight")` clean
- **Max feedback latency:** 30 seconds

## Manual-Only Verifications

Re-mapped from Phase 19 (D-23). Requires real WLED hardware on LAN. Run once before phase close.

| Behavior | Decision Ref | Why Manual | Test Instructions |
|----------|--------------|------------|-------------------|
| **V1 — Live LED color** | D-22 (gradient contract) + D-01..D-02 (refresh) | Requires physical strip update at ~60 Hz; no automated equivalent for visual color verification | Configure a segment on WLED device (via WLED app/web UI). Register device in HPC (initial fetch fires per D-02). Open WLED tab. Drag segment chip onto a canvas region. Start streaming. Point region at a known solid color in the capture source. Physical strip's segment LEDs match the region color within 1 frame. |
| **V2 — Chip-vs-strip color parity** | D-09 (palette anchored to seg_index) | Visual comparison across two UI surfaces | Configure 5 segments on the WLED device. Register and refresh. For each `seg_index ∈ {0..4}`: the strip's zone fill color equals the LightPanel chip color (both call `channelColor(seg_index)`). |
| **V3' — Refresh roundtrip (boundary change)** | D-02 + D-14 + D-16 | WLED-side configuration change cannot be automated without a real device | Configure two adjacent segments on the WLED app. Refresh in HPC. On the WLED side, change boundary (reduce seg 0 length, grow seg 1). Click the per-device Refresh button in HPC. Strip in HPC re-renders with new ranges; no assignment loss; no toast. |
| **V4 — Full-stack restart persistence** | D-12 + D-20 (cache on disk) | Process lifecycle + browser reload boundary | Register a device. Refresh once (populates `wled_seg_cache`). Drag a segment onto a region. Change orientation to a non-default. Restart backend (`uvicorn`). Reload browser. Strip layout (from cached segs), assignment, and orientation all survive. No device contact required to render the strip post-restart. |
